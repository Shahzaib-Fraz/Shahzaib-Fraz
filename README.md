## 👋 About Me

I'm a final-year **B.S. Data Science** student at **PUCIT, University of the Punjab, Lahore**, and a **Backend and Applied AI Engineer**. I build LLM-powered multi-agent systems and RAG pipelines, and I ship production-style backends with FastAPI, PostgreSQL and async SQLAlchemy, backed by CI/CD and Docker.

- 🤖 Building multi-agent systems with **LangChain** and **LangGraph**
- 🔎 Designing **RAG pipelines** and vector search (pgvector, ChromaDB, FAISS, Pinecone)
- 🔐 Backend engineering: auth (JWT, OTP email verification), migrations, rate limiting, test suites
- ⚙️ CI/CD with GitHub Actions, containerized services, MLOps with MLflow and DVC
- 💼 Backend AI Engineer Intern at **PentaCoders**: backend services, webhooks and voice pipelines
- 💻 Freelance **AI/ML & Backend Developer** on Upwork: FastAPI, RAG pipelines and LLM integrations
- 🎓 Machine Learning Specialization (Andrew Ng, Coursera), plus certifications from Microsoft, Google and IBM
